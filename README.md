# 🎨 Sortopia - The Sorting Game

**Version 1.1.0** | [Live Demo](https://awormus.github.io/sortopia) | [Changelog](CHANGELOG.md)

Welcome to **Sortopia**, the magical world of sorting! A fun, interactive single-page application where you drag and drop items to put them in the correct order.

## 🌟 Features

### 🎮 **Core Gameplay**
- **Drag & Drop Interface**: Intuitive reordering with smooth animations
- **Mobile-Friendly**: Touch-optimized for phones and tablets
- **Desktop Support**: Traditional mouse interactions for desktop users
- **Instant Feedback**: Color-coded results show correct and incorrect placements

### 🛠️ **Create & Share**
- **Challenge Creator**: Simple text-based editor for creating custom challenges
- **Custom Titles**: First line becomes your challenge name
- **Share Links**: Generate URLs to share challenges with friends
- **Base64 Encoding**: No server required - everything encoded in the URL

### 💾 **Smart Storage**
- **Auto-Save**: Progress automatically saved to local storage
- **Resume Games**: Pick up where you left off
- **Reset Option**: Clear all data for a fresh start

### 🎨 **Beautiful Design**
- **Modern UI**: Gradient backgrounds and smooth animations
- **Responsive Layout**: Works perfectly on all screen sizes
- **Touch-Friendly**: Optimized button sizes for mobile devices
- **Visual Feedback**: Hover effects and drag animations

## 🚀 Quick Start

### Play Online
Visit the live demo: **[Play Sortopia](https://yourusername.github.io/sortopia)**

### Local Setup
1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. No installation or dependencies required!

### Create Your First Challenge
1. Click **"Create Challenge"**
2. Enter your challenge title on the first line
3. Add items to sort, one per line (first = earliest, last = latest)
4. Click **"Create Challenge"**
5. Share the generated link with friends!
